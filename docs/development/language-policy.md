# Language policy

| Audience / artifact | Language |
|---------------------|----------|
| `README.md` | English (end-user install and usage) |
| `docs/` (SSOT specifications) | English (aligned with README) |
| GitHub Issues and PR titles/bodies | Japanese |
| Commit messages | Japanese preferred (Conventional Commits; see `.rulesync/rules/git.md`) |
| Source code comments and identifiers | English |

Agents and humans should not translate user-facing README content into Japanese in the same files; add Japanese context in Issues/PRs instead.
